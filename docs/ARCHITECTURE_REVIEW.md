## 🔍 Detailed Component Audit

### 1. Firewall & Perimeter Defense
*   **Current State**: The system primarily uses the `ebpf` agent which leverages XDP for high-speed packet drops.
*   **Legacy Hooks**: `ufw` and `iptables` remain in the `SystemExecutor` whitelist. `FirewallPlugin.ts` still checks for `ufw` status as a fallback.
*   **Recommendation**:
    *   Remove `ufw` from the bootstrapper and permissions scripts.
    *   Complete the transition to `nftables` via the `nftables` crate if a non-eBPF fallback is required.

### 2. VPN & Anonymization
*   **Current State**: The `vpn` sidecar is currently a **stub**. It simulates connection logic and relies on the host having `wg-quick` installed.
*   **Legacy Hooks**: `wg` and `wg-quick` are heavily relied upon in the Deno orchestrator.
*   **Recommendation**:
    *   Implement native WireGuard configuration using the `netlink-packet-wireguard` crate for Linux.
    *   Integrate `wireguard-rust` for a cross-platform user-space implementation.
    *   Explore `Arti` (Tor in Rust) for the TOR stealth mode in `AnonymizationService`.

### 3. PCAP & Traffic Analysis
*   **Current State**: `pcap` sidecar has a native PCAPng writer but the actual packet capture is simulated/stubbed.
*   **Legacy Hooks**: `tcpdump` is whitelisted and used by several platform-specific providers.
*   **Recommendation**:
    *   Implement raw socket capture using `pnet_packet` or `af_packet` in the `pcap` agent.
    *   Remove `tcpdump` from the whitelists once raw socket parity is achieved.

### 4. Scanner (Rootkit & Malware)
*   **Current State**: Native `RKH_SCAN` performs basic hidden directory and memory anomaly checks.
*   **Legacy Hooks**: `rkhunter` and `clamscan` are still present in the whitelist and used for broader signature-based detection.
*   **Recommendation**:
    *   Integrate `yara-rust` into the `scanner` agent for high-performance, native signature matching.
    *   Expand `RKH_SCAN` to audit `/proc` and kernel symbols natively, removing the need for `rkhunter`.

## 🛠️ Remaining Third-Party Dependencies
The following tools are still whitelisted in `src/orchestrator/infrastructure/system/system_executor.ts` and should be targeted for removal:
*   `ufw`
*   `iptables`
*   `clamscan`
*   `rkhunter`
*   `tcpdump`
*   `wg-quick` / `wg`

## 🚀 Conclusion
The architecture has successfully offloaded high-frequency tasks (FIM, Process Blocking) to Rust. The primary remaining "bloat" is the dependency on external networking binaries (`ufw`, `wg-quick`). Prioritizing the native WireGuard implementation and raw socket PCAP capture will achieve a "Hermetic" security posture.
