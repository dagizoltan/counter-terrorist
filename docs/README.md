# Project Documentation

This folder contains the linear solution path for Counter-Terrorist.

## Follow this sequence
1. `01_overview.md` — define the problem, goals, scope, and success criteria.
2. `02_system_design.md` — review the architecture, component responsibilities, and data flow.
3. `03_roadmap.md` — follow the phased implementation path from secure foundation to production readiness.
4. `04_security_strategy.md` — understand the threat model, controls, and validation checklist.
5. `05_handover.md` — finalize deployment, evaluation, and handover requirements.

Each primary summary is backed by a numbered folder of detailed documents.

## How to use this folder
Follow the numbered summaries in order. After each summary, use the matching numbered folder for detailed implementation, architecture, and handover support.
